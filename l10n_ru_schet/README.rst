===========================================
Proforma to Schet (RU) for Odoo 16
===========================================

Модуль заменяет стандартный отчёт **PRO-FORMA Invoice** в Odoo на отчёт **Счёт**
и обновляет email-шаблон, чтобы к письму прикреплялся новый документ.

Функции
-------
- Заменяет привязку стандартного отчёта **Pro-Forma Invoice** к заказам.
- Настраивает email-шаблон для отправки **Счёта** клиенту.
- Упрощает документооборот, исключая дублирование отчётов.

Установка
---------
1. Скопируйте папку ``l10n_ru_schet`` в директорию ``addons``.
2. Перезапустите сервер Odoo.
3. Активируйте режим разработчика.
4. В разделе **Приложения** найдите модуль *Proforma to Schet (RU)* и установите его.

Использование
-------------
- В форме **Заказа на продажу** выберите действие **Печать → Счёт**.
- При отправке email из заказа к письму будет прикреплён новый отчёт **Счёт**.
- Старый отчёт **Pro-Forma Invoice** автоматически отключается.
